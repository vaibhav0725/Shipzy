# shipzy-dashboard

The optional local web dashboard for [shipzy](https://www.npmjs.com/package/shipzy). You normally never install this yourself: `shipzy dashboard` offers to download it the first time, and keeps it in `~/.shipzy/dashboard-app`.

It listens on `127.0.0.1` only, behind a per-launch token, and calls the same shipzy CLI you already use, with your own AWS credentials.

- Documentation: https://shipzy.quantav.xyz/docs/dashboard
- Source and issues: https://github.com/vaibhav0725/Shipzy
